# Königskanonen V3 Physics

## Neu in V3
- Physikalisch simuliertes Geröll mit Masse, Schwerkraft, Winddrift, Abprall und Energieverlust
- Geröll kann beide Burgen beschädigen und eine Partie entscheiden
- Stoßwellen, Mündungsblitz, dynamische Schatten, Tiefenverläufe und Kamerawackeln
- Knallige Themenfarben mit pseudo-3D-gerenderten Burgen, Kugeln und Trümmern
- Tag, Nacht, Nebel und Nacht & Nebel
- PWA, Touch und iPad-Querformat

## Physikhinweis
Die Simulation ist eine reproduzierbare Arcade-Physik mit zeitbasiertem Integrationsschritt. Sie berücksichtigt Gravitation, Windkraft, Impuls, Masse, Dämpfung, Kollision und Sekundärschäden. Sie ist spielerisch abgestimmt, nicht als wissenschaftlicher Ballistiknachweis gedacht.
